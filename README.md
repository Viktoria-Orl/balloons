# Balloons Tours Website

🌐 [Live Demo](https://viktoria-orl.github.io/balloons/)

A visually engaging and responsive website for hot air balloon tours. Designed as a promotional landing page, it highlights the tour options, customer feedback, and a booking form to drive user interaction and conversion.

## Features

- **Fully responsive** layout with modern grid-based structure  
- **Hamburger navigation menu** for mobile and desktop views  
- **Hero section** with a bold call-to-action  
- **About section** describing the experience  
- **Adventure icons** highlighting unique aspects of the service  
- **Tour cards** with flip animations and pricing  
- **Video background** with a gradient overlay for testimonials  
- **Booking form** with name, email, and tour type selection  
- **Styled footer** with links and logo  

## Technologies Used

- HTML5  
- CSS3 (Flexbox, Grid, Animations, Media Queries)  
- Google Fonts (Roboto)  
- Custom Icon Font  
- Responsive Images (`srcset`, `sizes`)  
- Embedded Video Background (`.mp4` / `.webm`)
